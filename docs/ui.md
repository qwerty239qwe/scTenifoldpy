# Local Web UI

`scTenifoldpy` ships an optional local web UI for running scTenifoldNet,
scTenifoldKnk, or plain gene regulatory network (GRN) construction
without writing any code.

## Install & Launch

```bash
pip install "scTenifoldpy[ui]"
sctenifold-ui
```

This starts a local server (default `http://127.0.0.1:8000`) and opens it
in your browser. Everything runs locally — no data leaves your machine.

You can also run it as a module, or customize the host/port:

```bash
python -m scTenifold.webapp --port 8080 --no-browser
```

## Workflow

1. **Choose a workflow** — compare two conditions (scTenifoldNet),
   virtually knock out one or more genes (scTenifoldKnk), or just build a
   gene regulatory network from a single sample with no comparison or
   knockout ("Build GRN only").
2. **Provide a dataset** — click "Use synthetic example dataset" for an
   instant synthetic run, or "Use PBMC3k example" for real 10x Genomics
   PBMC data (the dataset behind the Seurat and Scanpy getting-started
   tutorials), downloaded and cached on first use. You can also upload
   your own data as a genes-by-cells CSV (gene names in the first
   column, cells as the remaining columns) or an AnnData `.h5ad` file
   (reading `.h5ad` needs the `anndata` package, included in the `ui`
   extra).
3. **Configure the run** — QC thresholds (minimum library size / gene
   percent), and network construction options (backend, `n_jobs`,
   random state — not shown for "Build GRN only", which builds a single
   network with nothing to resample across). scTenifoldKnk additionally
   lets you pick the knockout gene(s), KO method, and strict lambda.
4. **View results** — once the job finishes, the browser shows either a
   ranked gene table (Distance, Z, FC, p-value, adjusted p-value) for
   scTenifoldNet/Knk, or a ranked edge list (Source, Target, Weight) for
   "Build GRN only" — downloadable as a CSV either way.

## Notes

- The UI exposes a curated subset of the full `compare_networks` /
  `virtual_knockout` / `cal_pcNet` keyword arguments — for full control
  (custom `network_kws`, `td_kws`, `ma_kws`, ...) use the
  [Class API](index.md) or [CLI](cli.md) instead.
- "Build GRN only" runs [`sc_QC`][scTenifold.core.sc_QC] then
  [`cal_pcNet`][scTenifold.core.cal_pcNet] — a single consensus network,
  not the resampled-and-denoised network scTenifoldNet/Knk build
  internally from many networks.
- Jobs run one at a time on a local background worker; there is no
  persistence across restarts.
- The synthetic "example dataset" is generated by
  [`get_test_df`][scTenifold.data.get_test_df], not real biological
  data.
- The PBMC3k example is real 10x Genomics data, QC-filtered the same way
  as Seurat's `CreateSeuratObject(min.cells=3, min.features=200)` and
  then downsampled (top ~300 most-expressed genes, ~260 cells) so the
  demo finishes in well under a minute. For the scTenifoldNet workflow
  it's split into two random halves — useful to see the pipeline run on
  real expression values, but not a comparison between two real
  biological conditions. It's downloaded from 10x Genomics and cached
  under `~/.cache/scTenifoldpy/pbmc3k/`.
