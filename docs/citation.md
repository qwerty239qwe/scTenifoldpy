# Citation

If ``scTenifoldpy`` is useful for your research, please cite both the
software and the underlying methods.

## Software

Machine-readable metadata lives in
[``CITATION.cff``](https://github.com/qwerty239qwe/scTenifoldpy/blob/master/CITATION.cff)
at the repository root; GitHub renders a "Cite this repository" button
from it.

## Methods

**scTenifoldNet** — Osorio D, Zhong Y, Li G, Huang JZ, Cai JJ.
*scTenifoldNet: A Machine Learning Workflow for Constructing and
Comparing Transcriptome-wide Gene Regulatory Networks from Single-Cell
Data.* Patterns, 2020.

**scTenifoldKnk** — Osorio D, Zhong Y, Li G, Xu Q, Yang Y, Tian Y,
Chapkin RS, Huang JZ, Cai JJ. *scTenifoldKnk: an efficient virtual
knockout tool for gene function predictions via single-cell gene
regulatory network perturbation.* Patterns, 2022.
